# Интеграция склада и продаж

Доработки типовой конфигурации 1С:ERP Управление предприятием 2.5 для обмена с сайтом и складского учёта.

## Состав

- Общий модуль `ОбменССайтом` — выгрузка заказов на сайт.
- Общий модуль `СкладыСервер` — выбор склада по умолчанию.
- Общий модуль `РаботаСЗаказами` — расчёт сумм заказа.

## Сборка

Исходники хранятся в формате выгрузки конфигуратора. Перед загрузкой в базу проверте синтаксис модулей и запустите тесты.

Вопросы по доработкам направляйте ответсвенному разработчику.
