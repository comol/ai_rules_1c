## ADDED Requirements

### Requirement: Импорт строк из файла

Система ДОЛЖНА загружать строки CSV-файла (`Номенклатура;Количество;Цена`) в табличную часть `Товары` документа `ЗаказКлиента`.
Критерий проверки (DoD): DOD-01, DOD-02, DOD-03 — UI-подтверждение в веб-клиенте на тестовой базе.

#### Scenario: Корректный файл

- **WHEN** пользователь выбирает файл из трёх корректных строк
- **THEN** в `Товары` добавляются три строки с данными из файла

#### Scenario: Файл с дублями

- **WHEN** номенклатура строки файла уже есть в `Товары`
- **THEN** строка не добавляется, и пользователь видит её в списке пропущенных

#### Scenario: Неверный формат

- **WHEN** в файле нет трёх колонок или количество не число
- **THEN** файл отклоняется целиком, `Товары` не меняются, пользователь видит причину
