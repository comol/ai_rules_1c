# Импорт строк заказа из локального файла

## Зачем

Менеджеры переносят строки заказов из файлов поставщиков вручную. Нужен импорт строк из локального CSV-файла в табличную часть `Товары` документа `ЗаказКлиента`.

## Что меняется

- Новая команда формы `ЗаказКлиента` «Загрузить строки из файла».
- Общий модуль `ИмпортСтрокСервер`: разбор файла, проверка формата, поиск дублей.
- При неверном формате файл отклоняется целиком, данные заказа не меняются.
- Строка, чья `Номенклатура` уже есть в табличной части, не добавляется повторно; пользователь получает список пропущенных строк.

## Влияние

- `Documents/ЗаказКлиента` (форма документа), `CommonModules/ИмпортСтрокСервер`.
- Проведение и движения документа не меняются.

## Definition of Done

- [ ] DOD-01 — корректный файл загружается: строки появляются в `Товары` с номенклатурой, количеством и ценой из файла (требование «Импорт строк», сценарий «Корректный файл»; метод — UI-подтверждение в веб-клиенте).
- [ ] DOD-02 — дубли не добавляются, пользователь видит список пропущенных строк (сценарий «Файл с дублями»; UI-подтверждение).
- [ ] DOD-03 — файл неверного формата отклоняется целиком, данные заказа не меняются (сценарий «Неверный формат»; UI-подтверждение).
- [ ] DOD-04 — изменённые модули проходят `syntaxcheck` → `check_1c_code` → `review_1c_code` на текущем состоянии (гейты 1–3).
- [ ] DOD-05 — финальное review изменения без нерешённых блокирующих замечаний.
